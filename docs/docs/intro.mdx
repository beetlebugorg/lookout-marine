<div className="lm-tail">

Lookout draws official ENC charts with the IHO portrayal rules, straight to the
GPU with Metal, Vulkan or Direct3D 12. The chart is built once and then lives on
the card, so panning, zooming, rotating and switching to the night palette never
stall — and an idle chart costs no battery.

**[Roadmap](roadmap.md)** — own ship, NMEA 0183, AIS, tracks and instruments.

The chart engine has its own documentation at
[tile57](https://github.com/beetlebugorg/tile57).

To learn why the project has this structure — one core and several native shells
written by AI — refer to
[the README](https://github.com/beetlebugorg/lookout-marine#how-we-use-ai).

</div>
